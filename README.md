# Engineering Explorer

necesito que me realices una pagina web para la materia de introduccion a la ingenieria que contenga los siguientes requerimientos;
 

Requerimientos Funcionales: 

RF01- Pantalla de bienvenida 

El sistema deberá mostrar una pantalla de bienvenida con una breve introducción sobre el propósito de la plataforma. 

RF02- Barra de navegación  

El sistema deberá mostrar una barra de navegación para acceder a los diferentes módulos. 

RF03- Visualización de ramas de la ingeniería 

El sistema debe permitir visualizar información estructurada sobre las diferentes ramas de la ingeniería (civil, mecánica, eléctrica, industrial, de sistemas, entre otras).. 

RF04: Historia y evolución de la ingeniería   

El sistema debe incluir una sección de historia y evolución de la ingeniería. 

RF05: - Temas De La Materia 
Contenidos de la materia introducción a la ingeniería. 

RF06: - Consulta de información detallada 

La plataforma deberá permitir acceder a información específica de cada rama de la ingeniería, incluyendo definición, áreas de aplicación, perfil profesional y campos laborales. 
 
RF07: - Navegación interactiva 

La plataforma deberá ofrecer mecanismos de navegación interactiva que faciliten la exploración de los contenidos por parte del estudiante. 

RF08: - Visualización de recursos multimedia 

La plataforma deberá permitir la incorporación y reproducción de imágenes, infografías, videos y recursos gráficos relacionados con las ramas de la ingeniería. 

RF09: -Visualización de agremiaciones de ingeniería  

El sistema debe mostrar información sobre las agremiaciones profesionales de ingeniería en Colombia (SCI, COPNIA, ACIEM, etc.). 

RF10: -Botón de búsqueda 

 El sistema debe ofrecer una función de búsqueda de contenidos por palabra clave o categoría. 

RF11: -Sistema de evaluación de afinidades  

El sistema debe incluir actividades o cuestionarios breves que permitan al estudiante autoevaluar su afinidad o interés por determinada rama. 

RF12: -Acceso desde dispositivos web 

La plataforma deberá permitir el acceso a los contenidos desde navegadores web en computadores, tabletas y dispositivos móviles. 

Requerimientos no Funcionales: 

RNF01: - (Usabilidad): La interfaz debe ser intuitiva y comprensible para estudiantes de primer semestre, sin requerir conocimientos técnicos previos. 

 

RNF02: - (Compatibilidad): El sistema debe ser accesible desde distintos navegadores web (Chrome, Firefox, Edge) y ser responsive (adaptable a dispositivos móviles y de escritorio). 

 

RNF03: - (Rendimiento): Las páginas y recursos visuales deben cargar en un tiempo razonable (por ejemplo, menos de 3-5 segundos) bajo condiciones normales de conexión. 

 

RNF04: - (Disponibilidad): La plataforma debe estar disponible el mayor tiempo posible mediante un servicio de hosting confiable. 

 

RNF05: - (Seguridad): Si se maneja información de usuarios, esta debe protegerse conforme a buenas prácticas (contraseñas cifradas, protección de datos personales según la ley colombiana de habeas data). 

 

RNF06: - (Escalabilidad): La arquitectura debe permitir agregar nuevas ramas de la ingeniería o contenidos adicionales sin rediseñar el sistema completo. 

 

RNF07: - (Mantenibilidad): El código debe estar documentado y organizado siguiendo buenas prácticas de desarrollo web, facilitando futuras actualizaciones. 

 

RNF08: - (Accesibilidad): La plataforma debe considerar principios básicos de accesibilidad web (contraste, tamaños de fuente legibles, navegación por teclado).
